# MeridianAlgo

**At the forefront of change.**

MeridianAlgo is a nonprofit organization building technology for students, companies, and everyone in between. All of our work is fully open source, transparent, and community driven.

## Our Mission

We believe good financial and technical tools should be free to use and easy to learn from. Every project we publish is open for anyone to read, use, and improve.

## Projects

Our repositories are grouped by focus area. Each one has its own README with setup steps and usage details.

### Core Tools and Platforms

* **[AraAI](https://github.com/MeridianAlgo/AraAI)**. AI powered financial analysis platform for stock volatility forecasting, market predictions, and portfolio optimization.
* **[FinAI](https://github.com/MeridianAlgo/FinAI)**. In house LLM research focused on finance based chats and requests.
* **[Cryptvault](https://github.com/MeridianAlgo/Cryptvault)**. Professional grade cryptocurrency analysis with advanced AI and ML predictions, 50+ pattern recognition, and terminal charts.
* **[FinDB](https://github.com/MeridianAlgo/FinDB)**. Multi source financial data scraper and database with daily automated updates.
* **[Midnight.AI](https://github.com/MeridianAlgo/Midnight.AI)**. Multi objective trading engine with a pretrained model, direct Alpaca API paper trading, and a built in backtester.

### Education and Learning

* **[Learn-Quant](https://github.com/MeridianAlgo/Learn-Quant)**. Beginner friendly utilities and examples that power our quantitative finance programs in Python and JavaScript.
* **[meridianalgo.org](https://github.com/MeridianAlgo/meridianalgo.org)**. Source code for our official website.

### Packages and Libraries

* **[Python-Packages](https://github.com/MeridianAlgo/Python-Packages)**. Official Python packages. Install with `pip install meridianalgo`.
* **[Javascript-Packages](https://github.com/MeridianAlgo/Javascript-Packages)**. Official NPM packages. Install with `npm install meridianalgo`.

### Utilities and Templates

* **[Pine-A-Script](https://github.com/MeridianAlgo/Pine-A-Script)**. Open source transpiler that converts TradingView Pine Script (v5 and early v6) into clean, executable JavaScript.
* **[No-Ticker-Left-Behind](https://github.com/MeridianAlgo/No-Ticker-Left-Behind)**. Global stock ticker database that generates a regularly refreshed stock universe.
* **[Apex-Analysis](https://github.com/MeridianAlgo/Apex-Analysis)**. Beginner friendly stock analysis and research platform. Public template.
* **[Basic-Sentiment-Analysis](https://github.com/MeridianAlgo/Basic-Sentiment-Analysis)**. FinBERT powered sentiment analysis for financial news. Public template.

### Blockchain and Crypto Infrastructure

* **[Interlink](https://github.com/MeridianAlgo/Interlink)**. Decentralized, high performance interoperability protocol that bridges fragmented blockchain ecosystems through trustless, zero knowledge cryptographic proofs.
* **[Unigroth](https://github.com/MeridianAlgo/Unigroth)**. A Rust implementation of the Groth16 zkSNARK that aims to be faster, more secure, and more adaptable.

Browse every repository on our [GitHub organization page](https://github.com/MeridianAlgo).
